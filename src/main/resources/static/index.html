    WebSocket / STOMP

    WS/wsSTOMP connect endpoint
    SUB/topic/tradesEach trade as it executes
    SUB/topic/bookDepth snapshot per place/cancel

    This page is subscribed to both topics right now — the Order Book and Trades tabs update from these broadcasts, not from polling.

    Request Body — POST /api/orders

    Price and quantity must both be positive; side must be BUY or SELL. Invalid input returns 400 with a structured error body.

    { "side": "BUY", "price": 100.50, "quantity": 25 }

    Matching Rules

    Price priority: best bid is the highest, best ask the lowest.

    Time priority: orders at the same price fill oldest-first.

    Trades execute at the resting order's price, not the incoming one.

    Every trade carries a monotonic sequenceNum for true match order.
